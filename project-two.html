01Project Overview

XD Scanner is a document-scanning utility built to replace the "flatbed scanner + manual crop + manual paste" routine most people still use to prep documents for passport-style print sheets.

Upload a front image, and optionally a back image — corner detection and alignment run automatically, straightening and cropping the scan as if it came off a real document scanner. The back scan can be skipped entirely if it's not needed.

Once aligned, the scan is auto-placed into a PSD passport-sheet template — same engine that powers the Passport Size Tool — and exported ready for print. The whole flow runs client-side, guided by a clean five-step wizard: Upload → Align Front → Align Back → Template → Preview.
